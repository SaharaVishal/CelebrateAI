# CelebrateAI 🎉

**An AI-powered Celebration and Event Planner**

CelebrateAI is a Streamlit-based application that uses Google's Gemini AI to help users plan celebrations and events with greater ease.

## Features

- AI-generated celebration and event ideas
- Theme suggestions
- Budget-aware planning
- Event timelines
- Vendor checklists

## Tech Stack

- Python
- Streamlit
- Google Gemini API

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/SaharaVishal/CelebrateAI.git
   ```

2. Navigate to the project folder:

   ```bash
   cd CelebrateAI
   ```

3. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Configure your Gemini API key using Streamlit secrets.

5. Run the app:

   ```bash
   streamlit run app.py
   ```
